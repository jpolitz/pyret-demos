Pyret “Work on GitHub” launcher — test build

A development build of the Pyret VS Code extension that imports code from code.pyret.org into a Pyret editor on vscode.dev.

Experimental, largely AI-generated, and for testing only. This isn't the Marketplace extension, and code.pyret.org doesn't have the button yet. The button below plays its part.

How it's meant to work

code.pyret.org copies the student's program to the clipboard and opens the launcher repository in vscode.dev. The launcher recommends the Pyret extension. Once the extension is installed, it offers to import the clipboard into a new .arr file and opens that file in the Pyret editor. Committing saves it to a fork on GitHub. Forks of a public repository are public.

Try it

  1. Uninstall the Marketplace Pyret extension in vscode.dev if you have it. This build uses the same ID (PyretProgrammingLanguage.pyret-parley).
  2. Edit the program below if you like, then click Work on GitHub. That copies the program and opens the launcher in a new tab.
  3. vscode.dev only installs extensions from the Marketplace or from localhost, so serve this build locally. In a terminal: 
    curl -LO https://jpolitz.github.io/pyret-demos/launcher/pyret-parley-0.44.100.vsix
unzip -q pyret-parley-0.44.100.vsix -d pyret-parley
npx serve@14.2.4 --cors -l 5123 pyret-parley/extension
    Then, in the vscode.dev tab, open the Command Palette (Ctrl+Shift+P / Cmd+Shift+P), run Developer: Install Extension from Location…, and paste:
    http://localhost:5123/
    Chrome will ask to let vscode.dev access your local network. Allow it. vscode.dev opens in Restricted Mode, so if the extension shows as disabled, click Restricted Mode in the status bar and trust the workspace.
  4. Right after installing, the extension should show “Import your code from code.pyret.org?”. It will preview http://localhost:5123/, because that's on your clipboard now. That's expected, and it shows the extension started. Note whether the prompt appeared on its own, only after trusting the workspace, or only after reloading the page. That's the main open question this build is meant to answer. Click Cancel.
  5. Come back here and click Work on GitHub again. In the new tab the extension is already installed, and the prompt previews your program. Click Import, accept the file name, and the Pyret editor opens.

If no prompt appears, run Pyret: Import code from code.pyret.org (clipboard) from the Command Palette.

Known gaps

  • Firefox and Safari may refuse the clipboard read. The extension then offers an empty file to paste into.
  • The “import into my fork” path for repeat visits hasn't been tested on vscode.dev.
  • vscode.dev and github.dev store data separately, so this build's state doesn't carry from one to the other.
