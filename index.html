Pyret experiment demos

Static snapshots. Everything runs in your browser; nothing is sent anywhere.

These are experimental and largely AI-generated demos. The five below come from unmerged experiment branches, not from released Pyret. Treat them — code, measurements, and claims alike — as research sketches rather than supported tools.

Lezer vs RNGLR — live parser comparison

Both of Pyret's parsers run on the same source as you type: tree agreement and timings, side by side. From the lezer experiment.

Bytecode VM visualizer

Edit Pyret, see the bytecode the interpreter back end would execute — disassembled live, without running it. From the interp-backend experiment.

cont vs promise — side-by-side codegen

The same program compiled by both stack backends at once: function beside async function, and a toggle that makes the flatness optimization strip awaits in front of you. From the Promise/async backend experiment.

Repartee — incremental-rerun notebook

A notebook where editing invalidates: change an earlier chunk and every result below it goes dashed, then Run re-evaluates from the earliest edit rather than from the top. The PLATEAU 2021 model on CPO's real editor. From the repartee-repl experiment.

Pyret CLI — single-executable downloads

Standalone pyret binaries for macOS (arm64/x64), Linux (x64/arm64) and Windows — no install, no Node. From the cli-binary experiment. Only the macOS arm64 build has been run; the rest are cross-compiled. On macOS, download with curl, not the browser — these aren't notarized, so a browser download gets quarantined and macOS calls it “damaged”. The release notes have the one-line fix either way.

A live Pyret program reading a real micro:bit over USB or Bluetooth, running on production Horizon CPO rather than a mock. Needs the hardware and a firmware flash.
