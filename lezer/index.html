        Both parsers run in this page and share Pyret's own tokenizer — the Lezer grammar's external
        tokenizer replays it, so only the grammar is under test. The verdict uses the same normalization
        as the offline compare-trees.js harness that produced the 553/553 corpus figure.
        On timing, believe the small number: these presets come out around 2–3× end-to-end
        (median of 5). The often-quoted 5.4× end-to-end / 11.5× parser-only are corpus-wide figures from
        timing.js over 553 files / 3.16 MB in node — a different mix, and the 11.5× excludes
        tokenizing, which is ~58% of Lezer's path. Live edits time a single parse and are noisier still.
